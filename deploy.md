# Deployment Guide

## Option 1: Vercel (Recommended)
1. Run: `npm install`
2. Run: `npm run build`
3. Run: `npx vercel --prod`

## Option 2: Netlify
1. Run: `npm install`
2. Run: `npm run build`
3. Drag the `dist` folder to netlify.com

## Option 3: GitHub Pages
1. Run: `npm install`
2. Update homepage in package.json
3. Run: `npm run deploy`
